# Image-Recovery-using-compressive-sensing
Compressive Sensing for Image Recovery
This repository contains implementation of compressive sensing techniques for image recovery from incomplete measurements, focusing on comparing Orthogonal Matching Pursuit (OMP) and Lasso regression approaches.

Overview
Compressive sensing is a signal processing technique that allows reconstruction of signals from significantly fewer measurements than traditionally required by the Nyquist-Shannon sampling theorem. This project demonstrates how images can be recovered from as few as 47% of the original pixels by exploiting sparsity in the DCT (Discrete Cosine Transform) domain.

Features
Image corruption simulation with controllable sampling rates
Block-based sparse recovery using OMP and Lasso algorithms
Cross-validation for optimal parameter selection
Comparative analysis of OMP vs. Lasso performance
